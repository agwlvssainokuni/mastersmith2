# 画面の配る成果物（frontend/dist と、そこに入る make-you-chic-ui の dist）を作る道具の一覧。
#
# 依存関係の脆弱性の検査（./gradlew verify の 8 の段、OSV-Scanner）では、npm の devDependencies の脆弱性は
# 原則として警告だけにする。ただし、ここに書いた道具は、配る JavaScript・CSS を生成・変換するため、
# 脆弱性が成果物に入り込むおそれがある。そこで devDependencies でも重大度 High 以上なら統合を止める。
#
# 書き方: 1行に1つのパッケージ名。末尾の * は前方一致（例: @rolldown/* は @rolldown/ で始まるすべて）。
# 道具を足したり入れ替えたりしたとき（Vite の版を上げたときなど）は、この一覧も見直す。
