# make-you-chic-ui への依頼の案 — role-menu

`vendor/make-you-chic-ui` はこのリポジトリから直接変えない（`project.md` の Forbidden）。make-you-chic-ui に無い部品が要るときは、設計の段で足りない点を一覧にし、上流への追加を先に依頼する（`team.md` の Way of Working）。この一覧は画面の段の案で、依頼の確定は Domain Design・Functional Design の段で行う。

## 必須: 入れ子のサイドバー

| 足りない点 | 要る理由（ストーリー） |
|---|---|
| 項目の入れ子（子の項目・開閉のボタン・段ごとの字下げ） | AC5.1.1・AC5.1.10 |
| 今の項目の `aria-current="page"` と見た目 | AC5.1.3・AC5.1.8 |
| 見出しで項目をまとめる（「業務」「管理」） | AC5.3.4・AC5.3.5 |
| ナビゲーションの名前と開閉のボタンの名前を言語に合わせて渡す口（今は日本語の固定） | AC5.1.12 |
| 開閉の状態を外から渡す・受け取る口（画面を移っても保つ、祖先を開く） | AC5.1.8・AC5.1.9 |
| リンクと開閉のボタンを分けた項目（テーブルと子の両方を持つ項目） | ストーリー D9 |
| Sidebar を AppShell の中で差し替える口、または Sidebar を部品として外へ出す | 骨組みで業務と管理の木を組むため（KB K-36） |
| 長い名前の省略と全体の名前（Tooltip か title） | AC5.1.10 |

## 任意（取り込まれたら置き換える）

| 足りない点 | 今回の扱い |
|---|---|
| 木の部品（開閉・選択・子の読み込み中） | frontend の `src/shared/` に作る |
| Dropdown の選択中の印（menuitemradio） | 文字「（使用中）」で代える |
| Table の行の開閉 | 素の table で作る |

## 間に合わないとき

依頼が、サイドバーを使う Bolt までに取り込めないときに、frontend の側で自前で作る形へ切り替えるかは、その時点で依頼者に諮る（`team.md`）。自前で作っても満たす受け入れ基準の切り分けは Delivery Planning で決める（ストーリーの確かめの R-05）。
