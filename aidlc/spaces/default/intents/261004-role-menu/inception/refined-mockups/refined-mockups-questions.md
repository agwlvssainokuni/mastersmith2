## 決まっていること（質問にしない）

- WCAG 2.1 AA、状態を色だけで表さない、結果を読み上げに伝える、日本語と英語の文言、取り消しにくい操作の前の確かめの表示（Modal は背景のクリックで閉じず、はじめのフォーカスを「やめる」に置く）は、前の Intent と同じ（ストーリーの「前提と読み方」の画面の共通の決まり）。
- N 階層のメニューは開閉のボタン（`aria-expanded`）と今の項目（`aria-current`）の形で、ARIA の tree の役割は使わない（ストーリー D12・AC5.1.1）。入れ子のサイドバーは make-you-chic-ui 側への追加を先に依頼する（`team.md`）。
- 同時の保存は後勝ち（M2: A）、作業ロールの変化は知らせない（M8: B）、権限の設定の画面にテーブルごとに業務のメニューに出るかを示す（M7: A、Should）。
- make-you-chic-ui にある部品: AppShell・Sidebar（平ら）・Table・Tabs・Modal・Select・RadioGroup・Dropdown・Badge・Toast・Alert・Tooltip・FormField・TextInput・Checkbox・Switch・Card・Icon。木を表す部品は無い（DSL の画面の `DslMenuTree` は frontend の側の自前の部品）。
