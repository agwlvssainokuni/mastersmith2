## 単位をまたぐもの（横断）

- **認可・API の分類（NFR1.2・NFR1.3）**: 注釈の定義と網羅の検査は U1、各機能の API への印は U3・U4・U5。
- **監査（FR12）**: 種類と出来事は U3（グループ）・U4（役割・権限・割り当て・import・作業ロール）。
- **漏えい（FR4.5・NFR1.6）**: 応答と TRACE のログの確かめは、利用者を扱う U3・U4。
- **画面の共通の決まり（NFR4）**: U6・U7。axe のすべての組（AC5.1.16）は U7。
- **E2E（NFR6.3、最大2本）**: F の流れは U6・U7 をまたぎ、I の流れは U7。どの単位で書くかはコード生成の計画で決める。

## 単位ごとのストーリーの並び（単位の中で作る順の目安）

- **U1**: 注釈と構造の検査 → 既存の API への印 → ESLint の制限と既存の違反の直し（US1.1 の AC1.1.15 の土台）→ 画面の登録の型の拡張（US5.3 の土台）→ 共有の木（US1.2・US4.2 の土台）。
- **U2**: 版 2 の型と JSON Schema・検証（US6.1）→ 既定の DSL の生成（US6.1）→ メニューの深さの上限（US5.2）→ 安全な YAML の読み込みの口（US3.1 の土台）→ 画面の文言（S10）。
- **U3**: グループの作成・名前の変更・削除 → メンバー → 問う口の定義（US2.1）。
- **U4**: ロール（US1.1）→ 設定と解決（US1.2）→ 割り当てと問う口の実装（US2.2）→ 作業ロール（US4.1）→ 自分の権限（US4.2）→ 受け渡し（US3.1）。
- **U5**: 業務のメニューの絞り込み → テーブルの置き場の問い合わせ（US5.1）。
- **U6**: ロールの一覧（US1.1）→ 権限の設定（US1.2、共有の木は U1）→ 割り当て（US2.2）→ グループ（US2.1）→ 受け渡し（US3.1）→ 利用者の管理の表示（US2.2）。
- **U7**: 作業ロールの切り替え（US4.1）→ 業務と管理のメニュー（US5.1・US5.3）→ テーブルの置き場（US5.1）→ 自分の権限（US4.2）。
