### 1. 共通の受け入れ基準の読み方に足す案

「共通の受け入れ基準の読み方」に次の3行を足す。

- **API の分類**: 足す API はすべて「公開・ログインだけ・管理者」のどれかに明示して分類され、分類の無い API があれば落ちるテストで確かめる（NFR1.3）。ロール・グループ・権限・割り当て・import・export は「管理者」、作業ロールの切り替え・自分の権限・業務のメニュー・準備中の画面の表示名は「ログインだけ」。
- **403 を確かめる利用者**: 管理の API の 403 は、権限が何も無い利用者ではなく、ロールを持ち作業ロールもある（管理者の印だけを欠く）利用者で確かめる（NFR1.2）。
- **停止中の利用者**: 停止中の利用者は、管理者の印やロールがあっても、この Intent で足す API をどれも呼べない（今のアクセストークンの認証で拒否される）。
