# make-you-chic-ui への依頼: サイドバーの N 階層のメニュー

依頼元: mastersmith2（Intent 261004-role-menu「F: ロールベースの権限の管理、I: メニュー・ナビゲーション（N階層）」）
対象の版: make-you-chic-ui `e82b651`（mastersmith2 が今固定しているコミット）
対象の部品: `AppShell`・`Sidebar`（`packages/make-you-chic-ui/src/components/AppShell/`）

## 1. 背景

mastersmith2 では、ログイン後の画面のサイドバーに、次の2つのメニューを並べて出したい。

- **業務のメニュー**: 利用者が書いた DSL の `menus` から作る N 階層の木。まとまり（子を持つ項目）とテーブルの画面を指す項目があり、利用者の作業ロールの権限で絞って出す。階層の深さは DSL の検証で上限を置く（目安 5 段）。
- **管理のメニュー**: 今と同じ平らな項目（管理・DSL・招待・利用者・ロール・グループ・権限の受け渡し）。管理者だけに出す。

今の `Sidebar` は `navItems: AppShellNavItem[]` の平らな一覧だけを受け取り、入れ子・見出し・今の項目の表示を持たない。また `Sidebar` は外へ出しておらず（`AppShell` の中でだけ使われる）、`AppShell` の側からサイドバーの中身を差し替える口も無い。mastersmith2 は `vendor/make-you-chic-ui` を直接変えない決まりのため、make-you-chic-ui の側で次の機能を足してほしい。

## 2. 今の作り（e82b651 の時点）

- `AppShellNavItem` は `label`・`icon?`（`IconName`）・`href`・`onClick?` だけを持つ。
- `Sidebar` は `<nav aria-label="メインナビゲーション">` の中に `<ul>` を1段だけ描き、各項目は `<a>`。`key` に `href` を使う。
- `aria-label` が日本語の固定。
- 今の項目を示す口（`aria-current` など）が無い。
- 畳んだ状態（`collapsed`）ではアイコンだけを出す。
- アイコン（`IconName`）は 18 種類（menu・chevron-down・chevron-up・close・check・bell・user・search・edit・trash・download・settings・home・list・info・success・warning・danger）。

## 3. 依頼する機能（必須）

### 3.1 項目の入れ子

- 項目が子の項目を持てるようにする（深さに上限を置かない。mastersmith2 の側で上限を守る）。
- 子を持つ項目（まとまり）には開閉のボタンを付け、`aria-expanded` で開閉の状態を示す。ボタンの読み上げの名前は「〇〇を開く」「〇〇を閉じる」のように項目の名前を含める（文言は 3.4 の口で渡せる）。
- 段ごとに字下げして、入れ子が見て分かるようにする。
- ARIA の `tree` の役割は使わず、開閉のボタンと `ul` の入れ子の形にする（キーボードは Tab でリンクと開閉のボタンを順にたどり、Enter・Space で開閉）。

### 3.2 リンクと開閉のボタンを分けた項目

- 1つの項目が「画面へのリンク（`href`）」と「子の項目」の両方を持てるようにする。名前はリンク、横の開閉のマークはボタンとして別々に操作できること。
- `href` の無いまとまり（移れない項目）も持てるようにする。名前は押せない文字として出し、開閉のボタンだけを操作できること。

### 3.3 今の項目の表示

- 今の画面に当たる項目に `aria-current="page"` を付け、色だけでなく太字や左の線などで見て分かるようにする。
- どの項目が今の項目かは、使う側（アプリ）が渡せるようにする（例: `currentHref` か、項目ごとの `current` の印）。

### 3.4 開閉の状態と文言を外から渡す口

- 開閉の状態を、使う側が渡す・受け取れるようにする（例: `expandedIds` と `onToggle`）。画面を移っても開閉の状態を保つ、直接開いた画面では今の項目の祖先を開く、といった扱いを使う側で行うため。
- ナビゲーションの領域の読み上げの名前（今は「メインナビゲーション」の固定）と、開閉のボタンの名前を、言語に合わせて渡せるようにする（mastersmith2 は日本語と英語を切り替える）。

### 3.5 見出しで項目をまとめる

- サイドバーの中を見出しで区切れるようにする（例: 「業務」「管理」）。見出しは読み上げでもまとまりの名前として伝わること（`h2` などの見出し、または `aria-labelledby` で結んだ区画）。
- 見出しの下に項目が1つも無いときに、空の見出しを使う側で出さないようにできること（中身の無い区画を渡さなければ出ない、で足りる）。

### 3.6 `AppShell` からサイドバーの中身を渡す口

- `AppShell` に、3.1〜3.5 の形の項目（見出しの区画の配列など）を渡せる口を足す。今の `navItems`（平らな一覧）は、今までの使い方を壊さないよう残す。
- または `Sidebar` を部品として外へ出し、`AppShell` に差し込めるようにする。どちらの形でもよい。

### 3.7 長い名前

- 長い名前は1行で省略し、全体の名前を Tooltip（または `title`）と読み上げの名前で出す。深い階層（5 段）と 40 文字ほどの名前でも、サイドバーの幅からはみ出さず、画面全体に横のスクロールが出ないこと。

### 3.8 畳んだ状態

- 畳んだ状態（アイコンだけ）での入れ子の扱いを決めてほしい。案: 畳んでいる間は1段目のアイコンだけを出し、まとまりを選ぶとサイドバーを開く。make-you-chic-ui の方針に合わせてよい。

## 4. 依頼する機能（任意。取り込まれたら mastersmith2 の自前の部品を置き換える）

| 機能 | mastersmith2 での今の扱い |
|---|---|
| 木の部品（開閉と選択、子を開いたときに読み込む間の表示）。権限の設定の画面の左の木に使う | mastersmith2 の `frontend/src/shared/tree` に自前で作る |
| `Dropdown` の選択中の印（`menuitemradio` と `aria-checked`）。作業ロールの切り替えに使う | 項目の名前に文字「（使用中）」を足して示す |
| `Table` の行の開閉 | 素の table で作る（DSL の違いの表と同じ） |

## 5. 受け入れの目安

mastersmith2 の側で次を確かめる（make-you-chic-ui の側のテストにも入れてもらえるとありがたい）。

- 開閉のボタンに `aria-expanded` があり、キーボードだけで最も深い項目までたどれる。
- 今の項目に `aria-current="page"` が付き、色だけに頼らずに分かる。
- 英語の表示で、ナビゲーションの名前と開閉のボタンの名前が英語になる。
- 見出しが読み上げでまとまりの名前として伝わる。
- 5 段の深さ・40 文字の名前で、360px・768px・1280px の幅ではみ出さない。
- ブランドカラーとテーマ（light・dark・system）のすべての組で、axe の違反が無い。
- 今の `navItems`（平らな一覧）を渡す使い方がそのまま動く。

## 6. 時期

- mastersmith2 では、この機能を使う作業（骨組みの画面、Bolt 9）を最後に置いている。それまでに取り込めないときは、mastersmith2 の側で自前のサイドバーに切り替えるかを、その時点で決める。
- 取り込みは、mastersmith2 の `vendor/make-you-chic-ui` の固定先を更新する専用のコミットで行う。
