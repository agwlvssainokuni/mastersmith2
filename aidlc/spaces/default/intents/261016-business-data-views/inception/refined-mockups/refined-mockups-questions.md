# Refined Mockups の質問（Intent 261016-business-data-views）

classic の範囲で Ideation の画面イメージと利用者の流れが無いため、画面イメージはストーリー（`aidlc/spaces/default/intents/261016-business-data-views/inception/user-stories/stories.md`）と要件から直接作る。書く前に、ストーリーの受け入れ基準を画面とサーバー側だけのものに振り分けて照らし合わせる（`project.md` の学び）。

## 決まっていること（質問にしない）

- WCAG 2.1 AA、ブランドカラーとテーマのすべての組での axe、取り消しにくい操作の確かめの表示（背景のクリックで閉じず、はじめのフォーカスは「やめる」）、画面の文言の日本語と英語、値と表示名を文字として出すことは、前の Intent とストーリーで決まっている。
- 一覧の状態（検索の条件・ページ・並び）は画面の中に持ち、道に検索の値を載せない（SM5）。保存せずに離れるときは確かめる（SM6）。`pattern` はサーバーだけ（SM4）。`password` のカラムは伏せる（SM3）。時差つきの型は UTC（SM7）。
- 画面の入口は、テーブルを指すメニューの項目（今の「準備中」の置き場）を一覧の画面で置き換える。表の右端に置く行の「操作」のメニューは `placement` を `bottom-end` にする（`project.md` の学び）。
- make-you-chic-ui の `Table` は、並べ替え（`aria-sort`）・ページ送り・文言の差し替え（`labels`）・横のスクロール（枠の `overflow-x`）・行の開閉を持つ。1ページの件数の選択と、横のスクロールの領域へのキーボードのフォーカスとラベルは持たない。`TextInput` は `type` を渡せる（日付・数の入力にブラウザの標準の入力を使える）。日付の選択の部品は無い。
