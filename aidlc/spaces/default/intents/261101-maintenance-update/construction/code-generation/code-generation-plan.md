## 大きな版の見送りの判定基準（要件のレビュー R-01、FR4.2）

大きな版の更新は、次のどれかに当たるときだけ見送る。見送ったものは `.github/dependabot.yml` の `ignore` に、理由（当たった基準）と外す時期を書く。

1. **直しの大きさ**: 更新に合わせて変える必要があるのが、設定・依存の宣言・型の注釈・呼び出しの名前の置き換えの範囲を超え、本体のソース（`src/main`・`frontend/src`）の振る舞いの変更（処理の流れ・API の形・画面の動き）を伴う。
2. **調べの時間**: `verify`・E2E の失敗の原因を、1つの部品につき 60 分調べても特定できない。
3. **上流の未対応**: 依存する部品（例: typescript-eslint・vitest のプラグイン）が新しい大きな版をまだ支援していない、と配布元の記述で確かめられた。
4. **決まりとの衝突**: 上げると決まり（axe の規則を外さない・Maven Central だけ・`ignore-scripts`・ライセンスなど）を破る必要がある。

基準に当たるか決めきれないもの、見送ると脆弱性（OSV の High 以上）が残るものは、生成を止めて依頼者に諮る。
