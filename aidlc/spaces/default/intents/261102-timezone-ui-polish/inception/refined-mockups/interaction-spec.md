# 操作の仕様（Intent 261102-timezone-ui-polish）

画面イメージ（`mockups.md` の S1〜S8）の操作・状態・キーボード・読み上げを、部品ごとに決める。出典: ストーリー（US1.1〜US5.3）、質問 Q1〜Q8。

## 1. 表示のタイムゾーンの選択（S1）

- **目的**: 利用者が時刻の欄で使うタイムゾーンを選ぶ（US1.1、FR1.1）。
- **部品**: make-you-chic-ui の `Select` を `FormField` で包む。
- **状態**:
  | 状態 | 見え方・動き |
  |---|---|
  | 通常 | 今の選択を見せる。先頭は「ブラウザに合わせる」 |
  | 変更した | 「保存する」が押せる。「元に戻す」で保存済みの値へ戻る |
  | 保存中 | 「保存する」が loading。選択は変えられない（今の言語と同じ） |
  | 拒否（サーバーが知らない名前） | 選択を残し、`FormField` の誤りに文を出す。フォーカスを選択へ戻す（AC1.1.3・AC1.1.4） |
  | 解釈できない保存値 | 選択の上に `Alert`（warning）。ブラウザのタイムゾーンで表示していると伝える。選び直せる（AC1.2.4） |
- **キーボード**: Tab で入り、矢印キー・文字入力で候補へ移り、Enter で決める（`Select` の標準の動き。NFR3.3）。
- **読み上げ**: ラベル「表示のタイムゾーン」、選んだ値（IANA の名前と時差）、案内文（`aria-describedby`）、誤り（`aria-invalid` と誤りの文）。

## 2. 表示のタイムゾーンの案内の1行（S2）

- **目的**: 今の表示のタイムゾーンと、変えに行く入口を伝える（Q2 B）。
- **部品**: 一覧・詳細の見出しの下の段落とリンク（`Link`）。
- **操作**: 「プリファレンスで変更」を押すとプリファレンスへ移る。
- **読み上げ**: 段落の文として読まれる。リンクの名前は「プリファレンスで変更」。
- **状態**: 設定あり／ブラウザに合わせている／解釈できない名前（3つの文）。読み込みの前は出さない（ストーリー Q6 A）。

## 3. 時点を表す型の入力欄（S3・S4）

- **部品**: `TextInput`（`FormField` で包む）。
- **入力**: `YYYY-MM-DD HH:mm:ss`（秒の端数 `.SSS`・`.SSSSSS` は任意）。全角の数字・区切りは受け付けない（誤りにする）。
- **検証のタイミング**: 欄を離れたとき（blur）と保存の押下で検証する。入力の最中には誤りを出さない（今のフォームと同じ）。
- **誤り**: 読めない値・存在しない時刻・（範囲の）始まりが終わりより後は、欄の下に誤りの文を出し、`aria-invalid` を付ける。保存の押下では最初の誤りの欄へフォーカスを移す（今の D9 と同じ）。
- **案内**: 書式の例と「Asia/Tokyo (+09:00) で入力」を、欄の下の文に置き、`aria-describedby` で結ぶ。
- **変えていない欄**: 更新の画面で、値を変えていない欄は送らない（AC2.5.1）。
- **読み上げ**: ラベル、必須、案内、誤り。

## 4. 夏時間の重なる時刻の選択（S3）

- **部品**: `RadioGroup`（legend「この時刻は2回あります。どちらですか」）。選択肢は「先（夏時間、-04:00）」「後（標準時、-05:00）」。
- **出る条件**: 入力した時刻が、表示のタイムゾーンで重なる時刻のとき、かつ値を変えた欄だけ（更新で変えていない欄には出さない）。
- **操作**: 選ぶまで保存の押下を誤りにし、ラジオの legend へフォーカスを移す。選んだら誤りは消える。時刻の欄を書き換えたら、選択は未選択に戻る。
- **キーボード**: 矢印キーで移り、Space で選ぶ（`RadioGroup` の標準）。
- **読み上げ**: fieldset と legend で、2択であることと今の選択が伝わる。

## 5. ホームのカード（S5）

- **部品**: `Card` のリンク（カード全体が1つのリンク）。見出しは h2「業務」「管理」、カードの並びは `ul`。
- **操作**: 押す（Enter）と移る。移り先は、テーブル・ビューはその画面、フォルダは最初に画面を持つ子孫の画面（AC3.1.4）。
- **フォーカス**: Tab でカードを上から下・左から右の順にたどる。フォーカスの印を見せる（今の部品の動き）。
- **読み上げ**: 名前（項目の名前）だけ。アイコンは `aria-hidden`（AC3.1.8）。
- **状態**: 読み込み中は出さない。案内（`Alert`）は今の動き。失敗のときの「もう一度」は、業務メニューと作業ロールを読み直す。
- **権限**: 管理の見出しとカードは、管理の権限を持つ人だけ。権限の無い人が管理の画面の道を直接開くと、403 の表示（AC3.2.3）。

## 6. サイドバーのアイコン（S6）

- **部品**: 今の `AppShell` のサイドバーの項目（アイコンの口）。
- **規則**: 管理の区画は、利用者＝`user`、ロールの受け渡し＝`download`、DSL＝`edit`。招待・グループ・ロールは取り込むまでアイコン無し。業務の区画は、DSL の `icon`（許す一覧で照らす）か、今の既定。
- **読み上げ**: アイコンは `aria-hidden`。項目の名前で伝わる（AC4.3.4）。
- **開閉・今の項目**: 今のサイドバーの動き（`aria-expanded`・`aria-current`）を変えない。

## 7. アプリのアイコン（S7・S8）

- ログイン: アイコンはアプリ名の上。飾りで、読み上げから外す。フォーカスを受けない。
- favicon: ブラウザのタブ。操作は無い。

## 8. キーボードだけでの1つの流れ（確かめる流れ）

1. プリファレンスを開き、Tab で表示のタイムゾーンへ移り、`Asia/Tokyo (+09:00)` を選んで保存する。
2. 保存の後、サイドバーから業務データの一覧を開く。見出しの下の1行が「Asia/Tokyo」になり、時刻の値に `+09:00` が付く。
3. 作成の画面で時点を表す型の欄に日時を入れて保存する。夏時間の誤りが出たときは、欄へフォーカスが戻る。
