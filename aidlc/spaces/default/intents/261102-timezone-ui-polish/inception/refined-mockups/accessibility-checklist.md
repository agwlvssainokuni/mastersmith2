# アクセシビリティの確認表（Intent 261102-timezone-ui-polish）

基準は WCAG 2.1 AA（要件 NFR3.1）。実際のブラウザの axe（E2E）と画面のテストの `vitest-axe` で確かめる。axe は、展開した状態・誤りを出した状態・長い名前・現実に近いデータ（2語の氏名など）で、ブランドカラーとテーマのすべての組について行う（`project.md`・`team.md`）。規則を外して違反を通さない（`project.md` Forbidden）。

## 2. 横断の確認

- **コントラスト**: 文字 4.5:1、大きな文字と UI の部品 3:1。ブランドカラーとテーマのすべての組（ライト・ダーク・OS に合わせる）で確かめる。誤りの文字・`Alert` の文字・アイコンも含める（`project.md`: 誤りの状態と2語の氏名で初めて出る不足があった）。
- **色だけで伝えない**: 誤り・注意は文でも伝える。テーブルとビューの違いは、名前や説明でも分かる（NFR3.2）。
- **フォーカス**: 保存の拒否・夏時間の誤り・保存の押下の後に、フォーカスの行き先が決まっている（誤りの欄・legend）。
- **拡大・狭い幅**: 375 px でも横の画面全体のスクロールが出ない。開いたメニュー・ポップアップが画面の中に収まる（`project.md`）。
- **言語**: `ja` と `en` の両方で、文言が欠けず、画面の言語の属性（`lang`）が合う。
- **動き**: アニメーションに頼らない。
