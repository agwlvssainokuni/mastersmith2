# アクセシビリティのチェックリスト — user-admin

目標は WCAG 2.1 AA（前の Intent と同じ、NFR7）。画面部品ごとに vitest-axe の検査を1件入れる（TP）。実際のブラウザでの検査（Playwright と axe-core）を足すかは設計で決める（TP の Q5 B）。足す場合は、誤りを出した状態と、2語の氏名（頭文字が2文字）を含むデータで、ブランドカラーとテーマのすべての組について行う（PM の学び）。

## 1. 知覚できる

- [ ] 管理者の印・状態（有効／利用停止）・ロック中・「あなた」は、色だけでなく `Badge` の文字で示す
- [ ] 印が無い・ロックしていないの「—」は、読み上げで「なし」と伝わる
- [ ] 文字と背景のコントラストは 4.5:1 以上（`Badge`・押せないメニューの項目・誤りの文字・危険のボタンを含む）。light・dark の両方で確かめる
- [ ] UI の部品（ボタンの枠・フォーカスの印・入力欄の枠）は 3:1 以上
- [ ] 文字の大きさ sm・md・lg のどれでも、列・ボタン・Modal の文字が重ならず読める
- [ ] 200% に拡大しても読める（狭い画面向けの形は作らないが、横にずらして読める。RQ7 C）
- [ ] 日時は利用者の言語の書式で、文字として読める

## 2. 操作できる

- [ ] 検索・検索を消す・各行の「操作」・メニューの項目・ページ送り・確かめ・入力のすべてをキーボードだけで操作できる
- [ ] Tab の順は、検索 → 一覧の行の「操作」 → ページ送り、の見た目の順と同じ
- [ ] フォーカスの印が見える（2px 以上、3:1 以上）
- [ ] メニューは Enter・Space・↓ で開き、↑↓ で移り、Enter で選び、Escape で閉じてボタンに戻る
- [ ] 押せない項目にもフォーカスが移り、理由が読める（`design-system-mapping.md` の G1〜G3 の扱いによる）
- [ ] 確かめ・入力の表示（Modal）は、フォーカスを中に閉じ込め、Escape で閉じ、閉じたら開いた行の「操作」ボタンに戻る
- [ ] 確かめの表示のはじめのフォーカスは「やめる」、入力の表示のはじめのフォーカスは氏名の入力欄
- [ ] 背景のクリックでは確かめ・入力の表示を閉じない（誤操作の防止）
- [ ] 送信中は二重に押せず、時間の制限で操作を打ち切らない
- [ ] `prefers-reduced-motion` のときは、開閉の動きを出さない
- [ ] 押せる部品の大きさは 44×44 CSS ピクセル以上を目安にする（行の「操作」ボタンを含む）

## 3. 理解できる

- [ ] 画面の言語（`lang`）が利用者の言語（ja・en）になる
- [ ] 見出しは `h1`「利用者の管理」から始まり、確かめ・入力の表示は見出しを持つ
- [ ] 入力欄（検索・氏名・言語）に見える label がある（入力欄の中の薄い文字だけにしない）
- [ ] 入力の誤りは、文字で、入力欄のすぐ近くに、直し方とともに示す。入力した値は消さない
- [ ] 業務の拒否は理由ごとの文言で、次にすること（先に停止を解く・ほかの管理者に頼む など）を示す（`mockups.md` の S5）
- [ ] 確かめの表示は、対象の氏名・メールアドレスと、操作の効き目を書く
- [ ] 権限が無いときの表示は「この画面を使う権限がありません」と、管理の画面の外へ移る手段を示す（RQ6 C）
- [ ] 文言と新しいエラーの説明文は ja・en の両方があり、en にするとすべて英語になる

## 4. 堅牢である

- [ ] 一覧は `table` の正しい構造（見出しの行・`columnheader`）で、表に名前（「利用者の一覧」）がある
- [ ] メニューは WAI-ARIA のメニューの形（`aria-haspopup`・`aria-expanded`・`menu`・`menuitem`）
- [ ] 押せない項目は `aria-disabled="true"` と、理由を `aria-describedby` で結ぶ
- [ ] Modal は `role="dialog"`・`aria-modal="true"`・`aria-labelledby`・`aria-describedby`
- [ ] 入力の誤りは `aria-invalid` と `aria-describedby`
- [ ] 読み込み中・成功・結果の件数の変化は `role="status"`、失敗は `Alert` で読み上げる
- [ ] 一覧の読み直しの間は、一覧に `aria-busy="true"`
- [ ] 行ごとの「操作」ボタンは、対象の利用者が分かる読み上げの名前を持つ（同じ名前のボタンが並ばない）
