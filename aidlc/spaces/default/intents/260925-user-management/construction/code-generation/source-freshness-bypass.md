# コード生成の段の承認の場を開くときに外した確かめ

- 日付: 2026-09-28
- 決めた人: 依頼者（外す理由と範囲の説明を聞いたうえで、選択肢 1 を選んだ）

## 外したもの

承認の場を開くとき（`report --result awaiting-approval`）に、環境変数 `AIDLC_SKIP_SOURCE_FRESHNESS=1` を付けた。これで外れるのは「段の中で変わったファイルが、すべてどれかの単位のレビューの対象の一覧（source-manifest.json）に載っているか」の確かめ全体である。Git が無視するファイルの分だけを外す指定はできない。

## 外した理由

段を始めたとき（2026-09-27T13:38:48Z）に控えたファイルの一覧と今の作業フォルダを比べて、181 件が「変わったのにどの単位の一覧にも載っていない」とされ、承認の場を開けなかった。フレームワークの比べ方の実装（`.claude/tools/aidlc-lib.ts` の `filesystemSourceIdentity`、`.claude/tools/aidlc-state.ts` の unclaimed の判定）を読んで、次のことを確かめた。

- 比べ方はタイムスタンプではなく、ファイルの中身の SHA-256、ファイルの増加、ファイルの消失で判定している。
- 一覧はファイルシステムを直接たどって作る。`.gitignore` は見ず、外すのは決まった名前のフォルダ（`.git`・`.gradle`・`node_modules`・`build`・`dist` など）だけである。サブモジュールは中のファイルも1つずつ一覧に入れる。
- 一方、レビューの対象の一覧に載せるときは `git check-ignore` で確かめ、Git が無視するファイルを拒否する。

181 件に含まれていたのは次のものだった。表示されたのは 10 件だけで、残りの 171 件の中身は確かめていない。

- `vendor/java-mustache-processor/` の中身。U1 でサブモジュールとして加えたため、控えに無かったファイルとして数えられた。
- `.idea/*.xml`。IDE が中身を書き換えた。
- `.env`。U1 の SMTP の設定のころに中身が変わった。中身は開いていない。
- `frontend/playwright-report/`・`frontend/test-results/`。E2E を流すたびに作り直されたり消えたりする。

アプリのソースではないうえ、数え方と載せ方の決まりが食い違っている。このため、「一覧に足す」ことも「元に戻す」こともできず、ファイルを直す手段では解消できない。

## 外したことで残る確かめの抜けと、代わりの確かめ

- Git が管理するアプリのソースの変更は、U1〜U8 のコード生成のレビュー（READY）と、develop のコミット（d1c1505 まで）で確かめられる。
- Build and Test で、`./gradlew verify` をもう一度通して確かめる。
- 数え方の食い違い（`.gitignore` を見ないこと、サブモジュールの中をたどること）は、フレームワークの不具合の候補として残す。
