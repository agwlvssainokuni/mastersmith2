## 2. 表示の設定に関わる確認

| 項目 | 確かめ方 |
|---|---|
| テーマ（ライト・ダーク）と文字の大きさ（小・標準・大）のどの組み合わせでも、文字のコントラストが 4.5:1 以上・部品が 3:1 以上 | jsdom では色のコントラストを評価できない見込みのため、確かめ方は NFR 要件の段で決める（ストーリーの「後の段に回す点」） |
| 文字の大きさを「大」にしても、項目やボタンが重ならず、横に動かさずに読める（表を除く） | 同上 |
| 画面の拡大（200%）で内容と操作が失われない | 同上 |
| テーマを選んだ時点で画面に当てる動き（S2・S4）で、フォーカスの位置が変わらない | 部品のテスト |
| `prefers-reduced-motion` のとき切り替えの動きを止める | 部品のテスト |

## 3. 招待メール（E1）

| 項目 | 内容 |
|---|---|
| 言語 | `<html lang>` を招待の言語にする |
| 構造 | 見出し・段落・リンクを HTML の要素で書き、表でレイアウトしない |
| リンク | ボタンの形のリンクに加え、URL をそのまま文字でも載せる |
| 色 | 色だけで意味を伝えない |
