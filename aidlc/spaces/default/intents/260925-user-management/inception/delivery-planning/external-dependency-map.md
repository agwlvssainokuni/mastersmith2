# External Dependency Map — user-management

Bolt は、1つ以上の単位をまとめて作り終え、動くものができる1回の作る区切りのこと（一覧は `bolt-plan.md`）。この文書は、このチームの外にあって Bolt を止めうるものを示す。

| 外のもの | 持ち主 | かかる時間の見込み | 止める Bolt | 遅れたときの手 |
|---|---|---|---|---|
| java-mustache-processor（自前の部品のリポジトリ） | 依頼者（別のリポジトリ） | サブモジュールで取り込めれば無し。Maven Central への公開に切り替える場合は、公開の準備と名前空間の確認の分（依頼者の作業） | B1（と B1 に依存する B3・B5） | 取り込みの形を決めるまで B1 のコード生成を止め、設計の段は先に進める |
| JVM の中で動くテスト用の SMTP の受け手の部品 | 外部の公開の部品（Maven Central） | 採用の前のライセンスの確認だけ | B1 | ライセンスが合わなければ別の部品にする |
| 手元でメールを見る受け手のコンテナのイメージ | 外部の公開のイメージ | 版を固定して取り込むだけ | B1（手元の確かめ） | 無くても自動のテストは JVM の中の受け手で行える |
| Maven Central・npm の取得 | 外部 | 無し（既存と同じ） | すべて | 既存の lockfile どおり |

- 実在の宛先・外部の SMTP には、配備先が決まるまで送らない（`project.md` の Forbidden）。そのため、外部のメールの配送の仕組みはこの Intent の外にある。
- ほかのチームの受け渡し・承認の待ちは無い（チームは依頼者と AI の1つ）。
