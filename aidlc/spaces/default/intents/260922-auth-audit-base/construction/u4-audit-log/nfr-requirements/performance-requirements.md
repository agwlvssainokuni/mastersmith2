# Performance Requirements — U4 監査ログ（u4-audit-log）

U4 の性能の要件。監査イベントの記録は要求と同じスレッドで行うため、その時間はログイン・ログアウト・アクセス拒否の応答時間に含まれる。測定の環境は、当面の配備先である開発者の PC 上のコンテナとする。

| ID | 要件 | 測り方 | 出典 |
|---|---|---|---|
| NFR1.1 | 監査イベント1件の書き込み（別のトランザクションの開始から確定まで）は、同時に 10 件の要求が来る状態で、95% が 50 ミリ秒以内とする | 書き込みの時間を測る（負荷の試験の中で） | Q2、NFR1 |
| NFR1.2 | 監査イベントの書き込みは、ログインとトークンの更新の API の目標（95% が1秒以内。U2 の NFR1.1・1.2）の内側に収まる | U2 の負荷の試験で、監査ログを有効にした状態で測る | NFR1 |
| NFR1.3 | 監査イベントの書き込みは、1件につき内部DBへの追記1回だけとし、ほかの表の読み取りを伴わない | 発行する SQL の回数を確かめる | U4 の決まり 1.1 |

NFR1.1 の値は設計上の目標であり、測定の結果に応じて NFR Design で見直す。
