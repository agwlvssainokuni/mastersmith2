# Observability Requirements — U4 監査ログ（u4-audit-log）

| ID | 要件 | 確かめ方 | 出典 |
|---|---|---|---|
| NFR10.3 | 監査イベントの書き込みに失敗したときは、アプリのログに ERROR で1回、失敗したことと記録しようとした全項目（メールアドレスを含む）をキーと値で出す | テスト | FR9.4、U4 の決まり 3.1 |
| NFR10.4 | 監査イベントのトレースIDは、同じ要求のアプリのログのトレースIDと一致する | テスト（FR10.2 の2つ目の受け入れ基準） | FR10.2、U4 の決まり 2.4 |
| NFR10.5 | 監査イベントの書き込みの失敗の件数（アプリのログの該当する ERROR の件数）を、運用で見る指標の候補とする。本Intentでは指標を外部に公開しない | 配備先が決まったときに確かめる | operation フェーズの決まり |
