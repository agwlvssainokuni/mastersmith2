# Functional Design — Questions（U3 管理画面のアクセス制御 / u3-access-control）

U3 の受け持ち（`aidlc/spaces/default/intents/260922-auth-audit-base/inception/units-generation/unit-of-work.md` の U3）について、振る舞いの決まりを確認します。対象は、ログイン後の画面の「管理」と管理者向け領域（FR2.2）、管理者のみの API のサーバー側の判定（FR8.1、FR8.2）、アクセス拒否の出来事の通知です。

決定済みの事項（再確認はしません）:
- 未認証は 401、管理者フラグの無い利用者は 403、管理者は利用できる。画面でメニューを隠すことは、サーバー側の判定の代わりにしない。
- 管理者かどうかは、要求ごとに内部DBから読んだ値（U2 の AuthenticatedUser）で判断する。
- 権限不足によるアクセス拒否は、出来事として知らせ、U4 が監査ログに記録する。
- 管理者向け領域は、表示するときに管理者専用の確認用 API を呼び、拒否されたら表示しない。
- ログイン中の非管理者が管理者用の画面の URL を開くと、画面側は「ページが見つかりません」を表示する（U1 の決まり 7.5）。

### Q1. どの API を「管理者のみ」とするかは、どう決めますか？

- A. URL の場所で決める。`/api/admin/` の下の API はすべて管理者のみとし、個々の API で書き忘れても守られるようにする
- B. API ごとに「管理者のみ」と宣言する
- X. Other (please specify)

[Answer]: A. URL の場所で決める。`/api/admin/` の下の API はすべて管理者のみとし、個々の API で書き忘れても守られるようにする

### Q2. 管理者のみではない API は、既定でログインを求めますか？

- A. 求める（既定で拒否）。`/api/` の下の API は、公開すると明示したもの（ヘルスチェック、問題の種類の説明ページ、ログイン・トークンの更新・ログアウト）を除いて、すべてログインを求める
- B. 求めない（既定で許可）。ログインが要る API で個別に宣言する
- X. Other (please specify)

[Answer]: A. 求める（既定で拒否）。`/api/` の下の API は、公開すると明示したもの（ヘルスチェック、問題の種類の説明ページ、ログイン・トークンの更新・ログアウト）を除いて、すべてログインを求める

### Q3. アクセス拒否の出来事として知らせる（監査ログに記録する）のは、どれですか？

- A. 管理者のみの API で、ログイン中だが管理者でない利用者を拒否した場合（403）だけ
- B. A に加えて、管理者のみの API を未ログインで呼んで拒否した場合（401）も知らせる
- X. Other (please specify)

[Answer]: B. A に加えて、管理者のみの API を未ログインで呼んで拒否した場合（401）も知らせる

### Q4. 管理者向け領域を開いたときに確認用 API が拒否した場合（管理者フラグが外された直後など）、画面には何を表示しますか？

- A. 「ページが見つかりません」を表示する（URL を直接開いた場合の U1 の決まり 7.5 と同じ）
- B. 「この画面を表示する権限がありません」を表示する
- X. Other (please specify)

[Answer]: A. 「ページが見つかりません」を表示する（URL を直接開いた場合の U1 の決まり 7.5 と同じ）

### Q5. 管理者のみの API での 401 のうち、どれをアクセス拒否として記録しますか？

Q3 の回答（B）の確認のための追加の質問。アクセストークンの有効期限は5分のため、有効期限切れによる 401 は、管理者の普段の操作中にも約5分ごとに起きる（画面が自動で更新して送り直す）。

- A. 有効期限切れ以外の 401 だけを記録する（トークンが無い、形式が正しくない、署名が正しくない、利用者がいない）
- B. 有効期限切れを含め、すべての 401 を記録する
- C. Q3 を A（403 だけ）に変える
- X. Other (please specify)

[Answer]: A. 有効期限切れ以外の 401 だけを記録する（トークンが無い、形式が正しくない、署名が正しくない、利用者がいない）

## Consolidated Summary Confirmation

- 管理者のみの API: URL の場所で決める。`/api/admin/` の下はすべて管理者のみ
- ほかの API: 既定でログインを求める。公開するのは、ヘルスチェック、問題の種類の説明ページ、ログイン・トークンの更新・ログアウトだけ
- アクセス拒否の記録: 管理者のみの API での 403（管理者でない）と、有効期限切れ以外の 401（トークンが無い、形式が正しくない、署名が正しくない、利用者がいない）。有効期限切れの 401 は記録しない。そのため U2 は、401 の理由（有効期限切れかどうか）を U3 へ伝える
- 管理者向け領域で確認用 API が拒否した場合: 「ページが見つかりません」を表示する
