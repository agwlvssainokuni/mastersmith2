# Scalability Requirements — U3 管理画面のアクセス制御（u3-access-control）

| ID | 要件 | 確かめ方 | 出典 |
|---|---|---|---|
| NFR1.4 | U3 は状態を持たない（判定は要求ごとに行い、アプリのメモリに利用者ごとの情報を持たない）。そのため、複数台で動かす場合もそのまま動く | 設計の確認 | ADR-008 |
| NFR1.5 | アクセス拒否の出来事の件数は、利用者 50 名の想定で1日あたり数十件以内と見込む（監査ログの見積もり（U1 の NFR1.9）に含まれる） | 見積もりの記録（本書） | NFR1 |
