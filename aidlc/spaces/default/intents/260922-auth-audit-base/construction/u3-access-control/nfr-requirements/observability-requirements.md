# Observability Requirements — U3 管理画面のアクセス制御（u3-access-control）

| ID | 要件 | 確かめ方 | 出典 |
|---|---|---|---|
| NFR10.2 | 管理者のみの API での 403 と、有効期限切れ以外の 401 を、アクセス拒否の出来事（監査ログの記録項目にそろえる）として知らせる。有効期限切れの 401 は知らせない | テスト | U3 の決まり 3.1〜3.4 |
| NFR10.3 | 403 を返したときは、アプリのログに WARN で、code とトレースIDを出す（利用者の特定は監査ログで行い、アプリのログにはメールアドレスを出さない） | テスト | U1 の決まり 5.5 |
| NFR10.4 | 処理中のログには、U1 の仕組みでトレースIDが付く | テスト | FR10.2 |
| NFR10.5 | 管理画面へのアクセス拒否の件数（監査ログの ACCESS_DENIED の件数）を、運用で見る指標の候補とする。本Intentでは指標を外部に公開しない | 配備先が決まったときに確かめる | operation フェーズの決まり |
