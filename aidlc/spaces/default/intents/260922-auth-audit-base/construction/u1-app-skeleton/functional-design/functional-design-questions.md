# Functional Design — Questions（U1 アプリの骨格 / u1-app-skeleton）

U1 の受け持ち（`aidlc/spaces/default/intents/260922-auth-audit-base/inception/units-generation/unit-of-work.md` の U1）について、振る舞いの決まりを確認します。対象は、起動とヘルスチェック（FR1.1）、内部DBの接続設定（FR1.2）、構造化ログ・分散トレース・外部エクスポート（FR10.1〜FR10.4）、共通のエラー応答、画面の骨組みと差し込み口、表示言語（FR2.3）です。

決定済みの事項（再確認はしません）: ログは1行1件の JSON で標準出力へ出す。トレースは W3C Trace Context を引き継ぐ。OTEL の外部エクスポートは既定で無効。エラー応答は Problem Details に `code` を足した形。表示言語はブラウザの設定で日本語・英語を切り替え、どちらでもなければ日本語。差し込み口は、画面（ルート）・サイドバーの項目・ユーザーメニューの項目・ログイン状態の提供元の4つ。

### Q1. ヘルスチェックは何を確かめて応答しますか？

- A. アプリが動いていることに加えて、内部DBにつながることも確かめる。DB につながらなければ「異常」と応答する。応答には状態（正常／異常）だけを載せ、内訳（どこが異常か）は載せない
- B. アプリが動いていることだけを確かめる（DB は確かめない）
- C. 「動いているか」と「要求を受け付けられるか（DB を含む）」の2種類を分けて用意する
- X. Other (please specify)

[Answer]: A. アプリが動いていることに加えて、内部DBにつながることも確かめる。DB につながらなければ「異常」と応答する。応答には状態（正常／異常）だけを載せ、内訳（どこが異常か）は載せない

- B. A に加えて、アプリ名とアプリの版（コミットのハッシュ）も載せる
- X. Other (please specify)

[Answer]: A. 標準の項目: 日時、レベル、ロガー名、スレッド、メッセージ、トレースID、スパンID、例外（あれば）、呼び出し側が渡したキーと値

### Q5. 後の単位（U2・U3）は、画面の骨組みの差し込み口へ、どのように登録しますか？

Units Generation で「後の単位は U1 のファイルを書き換えない」と決めています。

- A. 自動で見つける: 決まった場所・決まった名前の登録用ファイルを各機能に置き、骨組みが起動時にそれらをすべて自動で読み込む。後の単位は自分のフォルダにファイルを足すだけで済む
- B. 一覧に書き足す: 骨組みが持つ「機能の一覧」に、後の単位が1行ずつ書き足す。書き足しは U1 のファイルを変えることになるが、変更は一覧の1行に限る
- X. Other (please specify)

[Answer]: A. 自動で見つける: 決まった場所・決まった名前の登録用ファイルを各機能に置き、骨組みが起動時にそれらをすべて自動で読み込む。後の単位は自分のフォルダにファイルを足すだけで済む

## Q8. エラー応答の `type`（RFC 9457 の問題の種類を示す URI）は、どの形にしますか？

サマリー確認の後に、依頼者から「`type` に自サーバのベースURLにパスを足した URL を書き、その URL を開くと自サーバがエラーの説明を返す形にできないか」という検討の依頼があったため追加した質問。

- A. 既定は要求のベースURL（転送元ヘッダーを考慮）に `/api/problems/<種類>` を足して組み立て、設定でベースURLを固定値にもできる。`<種類>` は `code` を小文字・ハイフン区切りにしたもの
- B. ベースURLは必ず設定で与える（固定値のみ）
- C. 相対 URI（`/api/problems/<種類>`）とし、ホストを含めない
- X. Other (please specify)

[Answer]: A. 既定は要求のベースURL（転送元ヘッダーを考慮）に `/api/problems/<種類>` を足して組み立て、設定でベースURLを固定値にもできる。`<種類>` は `code` を小文字・ハイフン区切りにしたもの

- B. JSON のみ
- C. HTML のみ
- X. Other (please specify)

[Answer]: A. 要求に応じて切り替える。ブラウザで開けば HTML、API として呼べば JSON（Accept ヘッダーで判断）。言語は日本語・英語
