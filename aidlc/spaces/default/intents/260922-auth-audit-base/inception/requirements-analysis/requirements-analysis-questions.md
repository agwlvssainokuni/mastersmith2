### Q15. （Q6の確認）リフレッシュトークンを sessionStorage に置く場合の性質を、次のとおり理解したうえで採用しますか？

sessionStorage は、画面のスクリプトから読める保存領域です。そのため次の性質があります。

- 画面に不正なスクリプトが入り込んだ場合（XSS）、リフレッシュトークンを読み取られる可能性がある。Q5の作り直し（使ったものは無効）と、有効期限24時間で被害の範囲を抑える
- 同じタブでの再読み込みではログイン状態が続くが、タブやブラウザを閉じると消え、新しいタブではログインし直しになる
- リフレッシュトークンは Cookie ではなく、API の要求の本文やヘッダーで送る

- A. 理解したうえで sessionStorage を採用する
- B. HttpOnly の Cookie に変える（スクリプトから読めない。再読み込み・新しいタブでもログイン状態が続く）
- X. Other (please specify)

[Answer]: B. HttpOnly の Cookie に変える（スクリプトから読めない。再読み込み・新しいタブでもログイン状態が続く）
