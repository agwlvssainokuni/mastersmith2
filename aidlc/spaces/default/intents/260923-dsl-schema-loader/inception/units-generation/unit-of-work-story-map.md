## 複数の単位にまたがるもの

- **画面**: 画面の操作を含むストーリー（US1.1・US2.1・US2.2・US3.x・US4.x・US5.x・US6.2）は、U5 が画面の部分を受け持つ。画面の受け入れ基準（確かめる表示・処理中・読み上げ・日英）は U5 で確かめる。
- **3種類の DB**: 対象DB に関わる基準は、U1・U3 で3種類の DB について確かめる（US1.2）。U1 は最初の1種類から始める。
- **監査**: 各操作の監査の基準は U4 の中で、その操作と一緒に確かめる。
- **アクセス制御**: API の 401・403・200 は U4 の各 API で、すべての API を並べた一括の確かめと画面の入り口は U5 で行う。
