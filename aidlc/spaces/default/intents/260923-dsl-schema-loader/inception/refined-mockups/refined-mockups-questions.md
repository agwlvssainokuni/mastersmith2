# Refined Mockups — 質問

この Intent には Ideation の段（ラフな画面イメージ）が無いため、画面イメージはストーリー（`inception/user-stories/stories.md`）と要件から直接作ります。

ストーリーで決まっていることは質問にしていません。主なものは次のとおりです。
- 操作は管理者向け領域の中で行う
- 置き換え・適用・破棄の前に確かめる表示を出す
- 処理中の表示と二重の実行を防ぐこと
- 誤りの一覧のあとも入力を残すこと
- キーボードだけで操作でき、読み上げで結果が伝わること
- 画面は日英に対応する

今の管理者向け領域は、サイドバーの「管理」（`/admin`）に置き場の画面が1つあるだけです。使える部品は make-you-chic-ui の ThemeProvider・Icon・Button・FormField・TextInput・Textarea・Select・Checkbox・Switch・RadioGroup・Avatar・Badge・Card・Modal・Toast・Alert・Tooltip・Tabs・Dropdown・AppShell・Table です。ファイルの選択・違いの表示・コードエディターの部品はありません。
