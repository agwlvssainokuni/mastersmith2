# Requirements Analysis — 質問

依頼の元になった要件の資料（2.1〜2.9、3章、4章、9章の Intent A・D・E）で決まっていることは、質問にしていません。主なものは次のとおりです。

- DSL は YAML で書き、JSON Schema で構文を検証する
- 対象DB の接続先は DSL に含めず、`application.yml` の `mastersmith.target-db.*` に書く。対象DB は1つだけで、MySQL・MariaDB・PostgreSQL のいずれか
- スキーマの読み込みは、管理画面からの手動操作で行う。変更の自動検知はしない
- 読み込んだスキーマから既定の DSL を生成し、既存の DSL は全部上書きする（差分のマージはしない）
- 生成した DSL も完成品の投入も、プレビュー → 適用の2段階で反映する
- 管理画面での DSL の編集は範囲外。DSL の正本は、導入先の業務の側のリポジトリで管理する
- DSL の表示名は ja と en の2言語

ここでは、資料で決まっていない点、今回の Intent の範囲の境目、数値の目標を質問しています。
