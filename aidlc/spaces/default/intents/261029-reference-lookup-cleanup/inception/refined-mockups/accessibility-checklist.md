# アクセシビリティの確かめの一覧 — reference-lookup-cleanup

基準は WCAG 2.1 AA。画面部品ごとに vitest-axe の検査を 1 件入れ、実際のブラウザの axe（E2E）をブランドカラーとテーマのすべての組で流す（`team.md` の Testing Posture）。axe の規則・要素を外さない（`project.md` の Forbidden）。

## 画面ごとの確かめ

| 画面・部品 | 確かめること | 受け入れ基準 |
|---|---|---|
| M1 REFERENCE の選択 | ラベル・必須の印・`aria-required`。取得中は `aria-busy`。同名のラベルは値を併記。長いラベルは折り返すか省略して全文を取れる | AC1.1.6〜AC1.1.8 |
| M2・M3 入力不可 | 読み取り専用（`readonly`＋`aria-readonly`）。値を読み上げで確かめられる。説明文は文字で、`aria-describedby` で結ぶ。灰色だけで示さない。フォーカスが止まる | AC1.3.6・AC1.3.7 |
| M2 と M3 | 権限不足と候補が多いの文を分ける（読み上げでも見分けられる） | AC1.2.2・AC1.3.1 |
| M4 LOOKUP の項目 | 欄とボタンに名前（「{項目名}を選ぶ」「{項目名}をクリア」）。選んだ後にラベルと値が読まれる。NULL を許す項目に「クリア」 | AC2.2.7・AC2.3.1 |
| M5 ダイアログ | 名前（見出し）。開いたら最初の検索条件へフォーカス、閉じたら「選ぶ…」へ戻す。キーボードだけで、開く・条件を入れる・検索・行を選ぶ・閉じるができる。Escape で閉じる。背景をクリックしても閉じない | AC2.4.1・AC2.4.2・AC2.2.8 |
| M5 結果の表 | 表に `aria-label`。結果の件数の変化を `aria-live` で伝える。ページ送りの現在／総ページを読み上げる。「選ぶ」ボタンは行ごとの名前を持ち、1 行ずつ操作の対象 | AC2.4.3・AC2.2.2 |
| M5 状態 | 初期・条件が空・検索中・0 件・失敗の文言が別で、読み上げでも見分けられる | AC2.2.1・AC2.2.4〜AC2.2.6 |
| M5 長い名前・XSS | 長い名前は全文を取れる。`<script>`・引用符・`javascript:` は文字として出る | AC2.2.9・AC2.2.10 |
| M6 保存前の拒否 | 誤りのまとめ（`role="alert"`）へフォーカス。項目の近くの誤りを `aria-describedby`・`aria-invalid` で結ぶ。入力は消えない | AC3.1.7 |
| M7 必須の参照が入れられない | 項目の誤りとして、理由と次の手が文字で読める | AC1.5.1 |
| M8 狭い画面（375px） | ダイアログが画面に収まる。画面全体は横にスクロールしない。表の横のスクロール領域にフォーカスとラベル | AC2.4.5 |
| M9 一覧・詳細 | 入力不可の見た目が漏れない。変わらない | AC3.4.3 |

## 全体の確かめ

- キーボードだけで、作成の画面 → ピッカーを開く → 条件を入れる → 検索 → 行を選ぶ → ダイアログが閉じる → 保存、の流れを最後まで行える。フォーカスが見え、閉じ込められない（ダイアログの中を除く）。
- 画面の言語の切り替え（日本語・英語）で、ダイアログと誤りの文言が選んだ言語で出る（AC2.4.6）。
- axe（E2E）は、ピッカーを開いた状態・結果の一覧が出た状態・0 件・検索の失敗・入力不可（権限不足・候補が多い）・誤り状態・長い名前（100 文字以上、`<` を含む）・2 語以上の現実に近いデータを含め、ブランドカラーとテーマのすべての組で流す（AC2.4.4）。この検査は流れではないため、E2E の本数（参照ピッカーの代表の流れ 1 本）に数えない。
- 権限を欠く利用者の確かめは、E2E ではなく結合テストと画面のテストで行う（AC2.5.4）。
