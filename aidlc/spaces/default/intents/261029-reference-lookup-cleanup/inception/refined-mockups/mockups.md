## 2. M1 REFERENCE の選択（ふつう）（AC1.1.1〜AC1.1.3）

```
顧客 *必須   [ 山田商事 (C001)            ▼]
             ┌───────────────────────────┐
             │ 選んでください              │ ← NULL を許す項目だけ先頭に置く
             │ 青空商店 (C007)             │
             │ 山田商事 (C001)  ✓          │ ← ラベルの昇順、同じラベルは値の昇順
             │ 山本物産 (C013)             │
             └───────────────────────────┘
```

- 並びは参照先の `labelColumn` の昇順、同じラベルは `valueColumn` の昇順（AC1.1.1）。表示は「ラベル (値)」。ラベルが NULL の行は並びの最後で、表示は値だけ（AC1.1.2）。
- 更新の画面で保存済みの値は、選ばれた状態で出す（AC1.1.3）。
- 長いラベルは折り返すか省略して全文を取れる。同じラベルが複数あるときは値を併記して見分ける（AC1.1.8）。
- 選択肢を取得する間は、項目は入力できず「読み込み中」と分かる（`aria-busy`。AC1.1.7）。選択肢が 0 件のときは「選べる候補がありません」。必須の項目では保存できない理由を添える（AC1.1.6）。
- 取得が時間切れ・接続の失敗のときは、定義の取得全体の失敗として、既存の「つながらない」の表示（S6）に替える（AC1.1.4。部分的な失敗にしない）。

## 3. M2 入力不可（権限不足）（AC1.3.1〜AC1.3.3・AC1.3.6・AC1.3.7、Q4: A）

```
顧客 *必須   [ C001                        ]   ← 読み取り専用の欄に、保存されている値そのもの（ラベルは出さない）
             🛈 参照先を読む権限がないため変更できません   ← 説明文（文字。アイコンだけにしない）
```

- 作成の画面（保存済みの値が無い）では、欄は空で、説明文を出す。更新の画面では、保存されている値そのもの（参照先のラベルは出さない）を出す（AC1.3.3）。
- 欄は読み取り専用（`readonly`＋`aria-readonly`）で、フォーカスが止まり、値を読み上げで確かめられる。説明文は `aria-describedby` で欄に結ぶ。灰色だけで示さず、説明文を文字で出す（AC1.3.6・AC1.3.7）。
- LOOKUP も同じ見せ方にし、「選ぶ…」ボタンは出さない。参照先の表の名前は出さない（AC1.3.4）。
- 更新で、この項目の値は変えないため、保存の本文に含めない。ほかの項目の更新は成功する（AC3.2.1。サーバー側）。

## 4. M3 入力不可（候補が多い）（AC1.2.2〜AC1.2.4、Q5: A）

```
顧客         [ C001                        ]   ← 読み取り専用の欄に、保存されている値そのもの
             🛈 候補が多いため選べません。管理者に、検索（ピッカー）への切り替えを依頼してください
```

- 説明文は権限不足（M2）と別の文にし、見分けられる（AC1.2.2・AC1.3.1）。フォーム全体の定義の取得は成功し、ほかの項目は通常どおり表示される（AC1.2.3）。
- 保存済みの値は、値のみ表示する（AC1.2.4）。NULL を許す項目では、更新でも値を変えられない行き止まりになる（stories.md の X1。依頼者が受け入れた）。

## 5. M4 LOOKUP の項目と選んだ値（AC2.3.1〜AC2.3.3・AC2.2.3・AC2.2.7、Q3: A）

選ぶ前:
```
商品         [                             ] [選ぶ…]
             検索して選びます                  ← 説明文（欄は読み取り専用）
```

選んだ後（作成・更新）:
```
商品         [ 青いペン (P-0012)            ] [選ぶ…] [クリア]
```

- 入力欄は読み取り専用のテキスト欄で、選んだ行の「ラベル (値)」を並べる。ラベルが引けない（行が無い・読めない）ときは値だけを出す（AC2.3.2）。
- 「クリア」は NULL を許す項目だけに置く。押すと欄が空になる（AC2.2.7）。「選ぶ…」でダイアログをもう一度開ける。
- 更新の画面を開くと、保存済みの値のラベルを参照先から 1 件読んで出す（AC2.3.1）。一覧・詳細ではラベルを読まない（AC2.3.4）。
- ラベルは文字として出す（HTML として描かない。AC2.3.3）。

状態の一覧:

| 状態 | 見せ方 | 受け入れ基準 |
|---|---|---|
| 初期（検索前） | 「条件を入れて『検索』を押してください」。一覧は出さない | AC2.2.1 |
| 条件が空のまま検索 | 要求は送らず、「条件を入れてください」を条件の近くに出す。0 件の文言とは別 | AC2.2.5 |
| 検索中 | 「検索中」。「検索」を押せない（二重押しの防止） | AC2.2.6 |

- 検索条件の項目は `lookupSearch` の定義（カラムと演算子）に従う。演算子が選べる定義のときは、条件ごとに演算子を選ぶ部品を置く。検索の値の長さは 1,000 文字まで（AC2.1.4。サーバー側）。
- 行・ラベルの値は文字として出す（`<script>`・`<img onerror>`・`"`・`'`・`javascript:` を含んでも、HTML として描かない、リンクの先にしない。AC2.2.9）。
- 誤りは業務の言葉と該当の項目で伝え、DB の制約の文や内部の語は出さない（AC2.2.11）。

## 7. M6 保存前の確かめの拒否（AC3.1.2〜AC3.1.4・AC3.1.7）

```
┌──────────────────────────────────────────────────────────────────────┐
│ ⚠ 1 件の入力を確かめてください（顧客）                                 │ ← 誤りのまとめ（role="alert"。フォーカスを移す）
├──────────────────────────────────────────────────────────────────────┤
│ 顧客 *必須   [ 選んでください        ▼]                               │
│              ⚠ 顧客として選べない値です。選び直してください            │ ← 項目の近くの誤り（aria-describedby で結ぶ）
└──────────────────────────────────────────────────────────────────────┘
```

- 参照先に無い値と、権限のない参照先の値は、画面で区別できない同じ文にする（AC3.1.3）。409 `BUSINESS_REFERENCE_NOT_FOUND`（その項目の誤り）を、項目の近くに出し、`aria-describedby` と誤りのまとめに結ぶ。フォーカスは誤りのまとめへ移す。入力した値は消さない（AC3.1.7）。
- 保存中は保存・やめるを押せなくし「保存しています…」（既存の動作のまま）。

## 8. M7 必須の参照項目に値を入れられない（AC1.5.1・AC1.5.3、M1: A）

```
┌──────────────────────────────────────────────────────────────────────┐
│ ⚠ 1 件の入力を確かめてください（顧客）                                 │
├──────────────────────────────────────────────────────────────────────┤
│ 顧客 *必須   [                              ]                          │
│              ⚠ 必須の参照項目に値を入れられません                        │
│              参照先を読む権限がないためです。管理者に権限を依頼してください │ ← 理由（権限がない／候補が多い）と次の手
│                                              [やめる]  [保存]          │ ← 保存を押すとサーバー側が 409 で拒否する
└──────────────────────────────────────────────────────────────────────┘
```

- 作成の画面を開いた時点で、項目の近くに誤りとして示す（送信の前に分かる。AC1.5.1）。理由は権限がない／候補が多いのどちらかで、次の手（管理者へ権限、またはピッカー（LOOKUP）への切り替えを依頼）を添える。
- 保存を押しても、サーバーが 409 で拒否する（AC1.5.2。サーバー側）。NULL を許す項目では、値を空にして作成できる。

## 12. 要件・ストーリーとの差

- 要件・ストーリーは書き換えない。この段で決めたこと（Q1〜Q6）だけを足した。
- ストーリーの AC2.2.8（背景のクリックで閉じるか）は、Q2: A で「閉じない」と決めた。前の Intent の確かめる表示と同じ向き。
- make-you-chic-ui に足りない部品の洗い出しは `design-system-mapping.md`。上流への新しい依頼は出さない見込み（理由はそこに書いた）。
- 後の段で決める点: 演算子が選べる定義のときの部品の細部（Select の使い方）、ダイアログを開いたときの最初のフォーカス（検索条件の最初の入力）、「選ぶ」ボタンの読み上げの名前（例: 「青いペン を選ぶ」）。機能設計（フロントの設計）で決める。
