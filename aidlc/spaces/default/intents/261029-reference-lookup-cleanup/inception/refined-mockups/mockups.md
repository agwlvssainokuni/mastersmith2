## 2. M1 REFERENCE の選択（ふつう）（AC1.1.1〜AC1.1.3）

```
顧客 *必須   [ 山田商事 (C001)            ▼]
             ┌───────────────────────────┐
             │ 選んでください              │ ← NULL を許す項目だけ先頭に置く
             │ 青空商店 (C007)             │
             │ 山田商事 (C001)  ✓          │ ← ラベルの昇順、同じラベルは値の昇順
             │ 山本物産 (C013)             │
             └───────────────────────────┘
```

- 並びは参照先の `labelColumn` の昇順、同じラベルは `valueColumn` の昇順（AC1.1.1）。表示は「ラベル (値)」。ラベルが NULL の行は並びの最後で、表示は値だけ（AC1.1.2）。
- 更新の画面で保存済みの値は、選ばれた状態で出す（AC1.1.3）。
- 長いラベルは折り返すか省略して全文を取れる。同じラベルが複数あるときは値を併記して見分ける（AC1.1.8）。
- 選択肢を取得する間は、項目は入力できず「読み込み中」と分かる（`aria-busy`。AC1.1.7）。選択肢が 0 件のときは「選べる候補がありません」。必須の項目では保存できない理由を添える（AC1.1.6）。
- 取得が時間切れ・接続の失敗のときは、定義の取得全体の失敗として、既存の「つながらない」の表示（S6）に替える（AC1.1.4。部分的な失敗にしない）。

## 12. 要件・ストーリーとの差

- 要件・ストーリーは書き換えない。この段で決めたこと（Q1〜Q6）だけを足した。
- ストーリーの AC2.2.8（背景のクリックで閉じるか）は、Q2: A で「閉じない」と決めた。前の Intent の確かめる表示と同じ向き。
- make-you-chic-ui に足りない部品の洗い出しは `design-system-mapping.md`。上流への新しい依頼は出さない見込み（理由はそこに書いた）。
- **AC3.1.7 とのフォーカス先の差（決めた）**: AC3.1.7 は「フォーカスがその項目に移る」だが、既存の作成・更新の画面は、誤りのまとめ（`role="alert"`）へフォーカスを移し、各入力は `aria-invalid`・`aria-describedby` で結ぶ（既存の D22）。この画面は既存の動作を正とし、フォーカスを誤りのまとめへ移す。AC3.1.7 は、まとめへ移した後に Tab で該当の項目へ届くこと、項目の誤りが読み上げでも結ばれていることで満たす。ストーリーは書き換えず、この差を承認の場で見てもらう。
- **AC1.2.4 の文言の差（決めた）**: AC1.2.4 の文言「候補が多いため検索して選んでください」は、Q5 で決めた文言（管理者へ切り替えを依頼）に置き換える。REFERENCE の項目は検索で選べず（ピッカーは LOOKUP の項目の部品）、利用者ができるのは管理者への依頼だけのため。
- **M7 の作成と更新の分け（決めた）**: M7 の誤りは作成の画面だけに出す。更新で保存済みの値があるときは M2・M3 の説明文だけを出し、更新は成功する（AC1.5.4）。`FormField` は `error` があると説明文を出さないため、誤りの文に理由を含める（併記しない）。
- **既存の編集不可の列との形（設計で決める）**: 既存の作成・更新の画面は、編集不可の列を名前と値の読み取りの表示（`span`）で出す。M2・M3 は読み取り専用の欄＋説明文で、形が 2 通りになる。AC1.3.7（フォーカスが止まる・値を読み上げで確かめる）を満たすため、新しい形（読み取り専用の欄）を、権限不足・候補が多いの項目に限って使い、既存の編集不可の列は変えない。違いは設計で一言残す。
- **375px での「選ぶ」（設計で決める）**: 表の横スクロールで「選ぶ」が画面に見えないのを避けるため、狭い幅では「選ぶ」を最初の列に置く案を設計で決める（Q6: A の Table の使い回しは変えない）。
- **決めた点と未定の点**: ダイアログを開いたときの最初のフォーカスは、最初の検索条件に決めた（`initialFocusRef`）。未定は、演算子が選べる定義のときの部品（`Select`）の細部と、「選ぶ」ボタンの読み上げの名前に使う「行を見分けるラベル」の作り方。機能設計（フロントの設計）で決める。
- **状態の知らせ方**: 件数の変化は `aria-live="polite"`、「検索中」「条件を入れてください」は `role="status"`、検索の失敗は `role="alert"`、0 件と初期の案内は `role="status"`。ダイアログの閉じるボタンの名前（`closeLabel`）は「閉じる」「Close」（日本語・英語）。
